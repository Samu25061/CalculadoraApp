# Calculadora Android

## Descripción
Aplicación móvil desarrollada en Java y XML que permite realizar operaciones matemáticas básicas.

## Objetivo
Desarrollar una aplicación que aplique conceptos de programación móvil, diseño de interfaces y gestión de eventos.

## Funcionalidades
- Suma de números.
- Resta de números.
- Multiplicación de números.
- División de números.
- Validación de campos vacíos.
- Control de división entre cero.
- Limpieza de datos.

## Tecnologías
- Java
- Android
- XML
- Eclipse IDE
- GitHub

## Conceptos aplicados
- Vistas.
- Paneles.
- Botones.
- Etiquetas.
- Manipulación de texto.
- Eventos y listeners.
